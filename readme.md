# Web Programming

Kumpulan latihan dan proyek mata kuliah Web Programming.

## Daftar Isi
- **HTMLCSSBasic**: latihan dasar HTML dan CSS
- **HTML**: latihan struktur halaman HTML
- **JavaScript**: latihan dasar JavaScript
- **PHP**: latihan dasar PHP
- **FormProcessing**: memproses data dari form dengan PHP
- **IntroductiontoMySQLDatabaseandIntegrationwithPHP**: koneksi PHP ke MySQL
- **SimpleCRUDwithPHPandMySQL**: contoh CRUD sederhana
- **Blog**: sistem manajemen blog (CMS) dengan PHP, MySQL, dan JavaScript

## Teknologi
- HTML, CSS, JavaScript
- PHP 7.4+
- MySQL / MariaDB

## Cara Menjalankan
1. Pasang XAMPP (atau server lokal lain).
2. Letakkan folder di `htdocs`.
3. Untuk folder yang memakai database, impor file `.sql` terlebih dahulu di phpMyAdmin.
4. Buka `http://localhost/Web-Programming/nama-folder` di browser.

## Catatan
Repo ini dibuat untuk memenuhi tugas kuliah Web Programming.
